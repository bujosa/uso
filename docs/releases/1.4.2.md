# Uso 1.4.2

The Gemini row no longer passes off Antigravity's Claude and GPT quota as Gemini usage, and Uso finds Antigravity sign-ins made outside `agy`, such as T3 Code's.

## Install

Paste this in Terminal. It picks the build for your chip, checks the checksum and signature, installs Uso in `~/Applications`, and opens it without the Privacy & Security step:

```sh
curl -fsSL https://raw.githubusercontent.com/bujosa/uso/main/scripts/get.sh | bash
```

Or pick the zip for your Mac. Apple menu > About This Mac shows a Chip (Apple M…) or a Processor (Intel).

- **Apple silicon:** `Uso-1.4.2-macOS-apple-silicon.zip`
- **Intel:** `Uso-1.4.2-macOS-intel.zip`

Unzip it and move `Uso.app` to Applications. Quit the previous copy before replacing it. Open Uso and look in the menu bar.

macOS 14 or later. The app is locally signed and is not Apple-notarized. If macOS blocks its first launch, open System Settings > Privacy & Security and click Open Anyway; on macOS 14 you can instead right-click the app and choose Open. Each zip has a `.sha256` checksum.

## Changes

- **Honest Gemini bars.** Google's Antigravity quota can return only the "Claude and GPT models" group, with no limit for the Gemini models in use. Uso used to show that group as the Gemini row's Session and Week. Those bars are now labeled Claude & GPT 5h and Claude & GPT week (AG Claude in the menu bar), and the row says Google reports no limit for Gemini models in Antigravity. When Google does return a Gemini group, the row is unchanged.
- **Antigravity sign-ins outside `agy`.** With no `agy` session, Uso reads Antigravity's `acp_token.json` from `~/.gemini/antigravity-acp` or from T3 Code's Antigravity home, newest first. That file holds only a refresh token, so Uso gets a short-lived access token in memory for each refresh and writes nothing back.

## Validation

- `swift test`: 62 tests in 6 suites passed, adding the ACP token format and the Claude & GPT labels in the panel and menu bar.
- `swift format lint --strict` on the changed files passed.
- Live (`Uso --print`), Google AI Pro account: `Gemini [Google AI Pro] 100% left :: Claude & GPT 5h 0%, Claude & GPT week 0%`, with the new note.
- The ACP file's refresh, quota, and plan requests were replayed against Google with T3 Code's session on this Mac: refresh 200, quota 200, plan Google AI Pro. The packaged app on this Mac still reads the `agy` keychain session first, so the fallback path itself ran only in tests.

## Compatibility

No migration is required. The `agy` keychain session still wins when it exists.
