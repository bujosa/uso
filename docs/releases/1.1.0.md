# Uso 1.1.0

Muse Code, Grok Bot, account settings, and a new panel opening animation.

## Install

Download `Uso-1.1.0-macOS.zip`, unzip it, and move `Uso.app` to Applications. Quit the previous copy before replacing it. Open Uso and look in the menu bar.

Apple silicon, macOS 14 or later. The app is locally signed and is not Apple-notarized; if macOS blocks its first launch, right-click the app and choose Open.

## What's new

- **Muse Code:** detects the CLI's account login and reported plan. Shows the current window and weekly allowance when Meta returns them, with the actual window duration and reset dates. Pay-as-you-go and incomplete billing are labeled separately.
- **Muse app companion:** separate display preference and Open Muse action for the personal app. **Personal-app quota collection is not implemented in this version.**
- **Grok Bot:** its weekly or trial allowance is separate from Grok Build credits. Use the same signed-in account in Cursor and Grok Bot.
- **Settings:** see detected accounts and plans, choose independent panel and menu-bar visibility, open account management, and control startup and animation. Preferences survive relaunch.
- **Claude:** rereads the live Claude Code session, recognizes the reported Max 5×/20× tier, handles both quota response formats, and respects rate-limit delays.
- **Panel:** a short spring, staggered rows, animated meters, and an edge highlight. macOS Reduce Motion and the animation preference control these effects. Escape navigates back and closes; Command-R refreshes; Command-comma opens Settings.
- **Freshness:** failed refreshes label the last reading and remove stale values from menu rotation. Rejected sessions clear the previous account's quota.

## Muse Code setup and limits

Sign in with `muse login`. Uso reads that existing session; it does not send model prompts, refresh the login, write the Keychain, or save credentials. When required by macOS, choose Allow access in Uso to authorize the CLI's Keychain item.

Meta can verify a subscription while omitting its quota. Uso keeps the reported plan and shows Quota unavailable instead of assuming 100% remaining. API keys select pay-as-you-go and cannot read the subscription endpoint.

Account requests are bounded to once per credential every 5 minutes, including manual refresh. Cached readings keep their original time, expired windows are withheld, and a longer Retry-After delay takes priority.
