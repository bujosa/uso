# Uso 1.3.0

Gemini from the Antigravity CLI, shown only when this Mac has a Google sign-in. The X Subscription is one weekly pool, not three leftover meters.

## Install

Paste this in Terminal. It picks the build for your chip, checks the checksum and signature, installs Uso in `~/Applications`, and opens it without the Privacy & Security step:

```sh
curl -fsSL https://raw.githubusercontent.com/bujosa/uso/main/scripts/get.sh | bash
```

Or pick the zip for your Mac. Apple menu > About This Mac shows a Chip (Apple M…) or a Processor (Intel).

- **Apple silicon:** `Uso-1.3.0-macOS-apple-silicon.zip`
- **Intel:** `Uso-1.3.0-macOS-intel.zip`

Unzip it and move `Uso.app` to Applications. Quit the previous copy before replacing it. Open Uso and look in the menu bar.

macOS 14 or later. The app is locally signed and is not Apple-notarized. If macOS blocks its first launch, open System Settings > Privacy & Security and click Open Anyway; on macOS 14 you can instead right-click the app and choose Open. Each zip has a `.sha256` checksum.

## Changes

- **Gemini.** Uso reads the Antigravity CLI (`agy`) session from the login keychain and shows the 5-hour and weekly windows. The plan label prefers Google One's `paidTier` (Google AI Pro or Ultra) over Antigravity's `currentTier`, which stays Free even when that subscription is active. Sources without that session stay hidden, same as the rest of the panel.
- Sign-in needed stays visible if the Google session expires. Run `agy` and sign in with the Google account that has the plan.
- **The X Subscription.** When the unified plan is detected, the panel shows one **X Subscription** week instead of three leftover meters. Grok mix and prepaid fold into that row. Grok and Grok Bot stay in Settings. Legacy Cursor plans still show Auto / included / API and a separate Grok Bot week.
