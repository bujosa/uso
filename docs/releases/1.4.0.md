# Uso 1.4.0

Claude Ultra replaces Max 20×. The 5-hour session bar follows Anthropic's `is_active` flag. Included monthly API credits, extra usage, and a banked limit reset show when the account returns them.

## Install

Paste this in Terminal. It picks the build for your chip, checks the checksum and signature, installs Uso in `~/Applications`, and opens it without the Privacy & Security step:

```sh
curl -fsSL https://raw.githubusercontent.com/bujosa/uso/main/scripts/get.sh | bash
```

Or pick the zip for your Mac. Apple menu > About This Mac shows a Chip (Apple M…) or a Processor (Intel).

- **Apple silicon:** `Uso-1.4.0-macOS-apple-silicon.zip`
- **Intel:** `Uso-1.4.0-macOS-intel.zip`

Unzip it and move `Uso.app` to Applications. Quit the previous copy before replacing it. Open Uso and look in the menu bar.

macOS 14 or later. The app is locally signed and is not Apple-notarized. If macOS blocks its first launch, open System Settings > Privacy & Security and click Open Anyway; on macOS 14 you can instead right-click the app and choose Open. Each zip has a `.sha256` checksum.

## Changes

- **Claude Ultra.** Old Max 20× sessions label as Ultra. Max 5× labels as Max.
- **Session window.** The 5-hour bar and `Claude 5h` ticker line appear only while Anthropic marks that limit active. Verified Ultra drops the leftover session row so the headline is the week.
- **API credits.** When the plan includes monthly API dollars, the row shows remaining credits and the reset time. Extra usage on/off and a banked "Reset for free" offer show inside the row when the usage payload has them. Uso does not redeem a reset or turn extra usage on; that stays in Claude Settings > Usage.

- Live OAuth usage on this Mac: session `is_active: false`, week active, API credits `$250` remaining.

## Compatibility

No credential migration. Claude still reads the Claude Code session. Included API credits come from that same usage payload, not from an Anthropic Admin API key.
