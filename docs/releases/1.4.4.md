# Uso 1.4.4

Antigravity's Gemini 5-hour and weekly limits are back in Uso, and Antigravity's Claude & GPT pool stays inside the panel instead of rotating in the menu bar.

## Install

Paste this in Terminal. It picks the build for your chip, checks the checksum and signature, installs Uso in `~/Applications`, and opens it without the Privacy & Security step:

```sh
curl -fsSL https://raw.githubusercontent.com/bujosa/uso/main/scripts/get.sh | bash
```

Or pick the zip for your Mac. Apple menu > About This Mac shows a Chip (Apple M…) or a Processor (Intel).

- **Apple silicon:** `Uso-1.4.4-macOS-apple-silicon.zip`
- **Intel:** `Uso-1.4.4-macOS-intel.zip`

Unzip it and move `Uso.app` to Applications. Quit the previous copy before replacing it. Open Uso and look in the menu bar.

macOS 14 or later. The app is locally signed and is not Apple-notarized. If macOS blocks its first launch, open System Settings > Privacy & Security and click Open Anyway; on macOS 14 you can instead right-click the app and choose Open. Each zip has a `.sha256` checksum.

## Changes

- **Gemini 5-hour and weekly limits from Antigravity.** Google's `retrieveUserQuotaSummary` endpoint omits the Gemini Models group for older or CLI user agents (`antigravity-cli`), returning only the Claude and GPT pool. Uso now sends a current Antigravity client user agent (`antigravity/2.28.0`, or a newer installed `Antigravity.app` version), so Google returns both the Gemini Models group (Session and Week, plus Day if Google reports one) and the Claude & GPT group.
- **Keep Claude & GPT out of the menu bar ticker.** Antigravity's Claude & GPT pool still appears inside the Gemini detail view (and on the panel row if Google omits Gemini), but it no longer rotates in the menu bar as `AG Claude`.
- **Standalone Antigravity sign-in fallback.** Uso also reads `~/.gemini/jetski-standalone-oauth-token` when neither the `agy` keychain session nor the CLI token file is present.

## Validation

- `swift test`: 64 tests in 6 suites passed, adding coverage for keeping Claude & GPT out of the menu bar ticker, daily bucket parsing, and Antigravity user-agent version resolution.
- `swift format lint --strict --recursive Sources Tests Package.swift` passed.
- Live (`Uso --print`), Google AI Pro account: `Gemini [Google AI Pro] 47% left :: Session 53%, Week 15%, Claude & GPT 5h 0%, Claude & GPT week 0%`, with `Gemini 5h` and `Gemini wk` in the menu bar and no `AG Claude`.
- Packaged universal `Uso.app` plus signed Apple silicon and Intel release zips built and verified with `./scripts/package.sh` and installed locally via `./scripts/install.sh`.

## Compatibility

No migration is required. Existing `agy`, standalone Antigravity, and ACP sign-ins continue to work without re-authenticating.
